# Java Stream API – Coding Practice

A collection of Java programming problems solved using the **Java Stream API**. This repository focuses on improving problem-solving skills, understanding functional programming concepts, and writing clean and readable Java code.

The problems are designed to provide practical experience with Stream operations and strengthen Java fundamentals, particularly for coding interviews and backend development.

## 🎯 Objectives

- Strengthen understanding of Java 8 Stream API.
- Practise functional programming using Lambda Expressions.
- Improve problem-solving and logical thinking.
- Understand different ways to process and transform collections.
- Write clean, readable, and maintainable Java code.

## 🧠 Concepts Covered

The repository focuses on the following Java concepts:

- **Stream API:** Creating and processing streams.
- **filter():** Filtering elements based on conditions.
- **map():** Transforming elements into different forms.
- **sorted():** Sorting elements in ascending or descending order.
- **distinct():** Removing duplicate elements.
- **reduce():** Performing aggregation operations.
- **collect():** Collecting stream results into collections.
- **flatMap():** Flattening nested collections.
- **Optional:** Handling potentially absent values.
- **Collectors:** Grouping, partitioning, counting, and collecting data.
- **Lambda Expressions:** Writing concise functional code.
- **Method References:** Improving code readability.

## 🚀 Getting Started

Follow these steps to explore the repository locally.

**1. Clone the repository**

```bash
git clone https://github.com/sreepatil/java-streams-problems.git
```

**2. Navigate to the project**

```bash
cd java-streams-problems
```

**3. Open the project**

Import the project into your preferred Java IDE, such as Eclipse or IntelliJ IDEA.

**4. Run the programs**

Open the required Java class and execute its main method to explore the solutions.
